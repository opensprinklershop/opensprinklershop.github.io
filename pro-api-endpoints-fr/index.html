Complément API et plateformes OpenSprinklerPro

Version française complète du complément API et plateformes OpenSprinklerPro. Les chemins API et paramètres restent inchangés.

This addendum documents firmware endpoints and platform details that were added after the original 2.2.1 manual pages.

The OpenSprinklerShop firmware, including OpenSprinklerPro, uses its own firmware version numbering independent of upstream OpenSprinkler releases. Current OpenSprinklerShop firmware version: 2.4.0(228).

Corrections de plateforme

Endpoint Plateformes prises en charge Notes
/uc, /uu, /us, /ub ESP32, ESP8266 Firmware online update and full backup endpoints. Not available on OSPi/Linux builds.
/sx ESP32, ESP8266, OSPi Sensor-only configuration backup/import. Distinct from /ub.
/jw ESP32, ESP8266, OSPi Monthly water-usage data.
/tg, /tl, /ta, /tc, /tx ESP32 HTTPS certificate and ACME/Let's Encrypt management.
/rk, /rp, /ru ESP32 with ENABLE_RAINMAKER ESP RainMaker status, provisioning and unlink/reset flows.
/jm, /mm ESP32 with ENABLE_MATTER Matter pairing information and commissioning window.
/bd, /bs, /bc ESP32 with OS_ENABLE_BLE BLE scan and discovered-device management.
/ir, /iw, /zj, /zs, /zg, /zd, /zo, /zc ESP32-C5 with Zigbee/IEEE 802.15.4 support Radio mode and Zigbee gateway/client endpoints.

Mise à jour en ligne et sauvegarde

Endpoint Objectif
GET /uc?pw=... Check update manifest and report whether a newer firmware is available.
GET /uu?pw=... Start firmware update. Advanced parameters can override URLs and hashes: zu, mu, fu, zs, ms; vt selects zigbee or matter.
GET /us?pw=... Read update status and progress.
GET /ub?pw=... Export full controller configuration for app-side backup before update.

Certificats HTTPS et ACME

Endpoint Objectif
GET /tg?pw=... Read active certificate type, subject, issuer and validity.
POST /tl?pw=... Upload custom PEM certificate and key. Reboot afterwards.
GET /ta?pw=... Read ACME configuration and status.
POST /tc?pw=... Save ACME settings and optionally request a certificate.
GET /tx?pw=... Delete ACME data and return to the internal certificate.

RainMaker et Matter

Endpoint Objectif
GET /rk?pw=... Read RainMaker status. Optional reset_mapping=1 or factory_reset=1 perform maintenance actions.
GET /rp?pw=...&uid=...&key=... Start RainMaker provisioning.
GET /ru?pw=... Unlink RainMaker account and trigger reset/reboot behavior.
GET /jm?pw=... Read Matter commissioning state, QR-code URL and manual pairing code.
GET /mm?pw=...&t=300 Open Matter commissioning window; t is optional timeout in seconds, max 900.

Consommation d’eau et capteurs

Endpoint Objectif
GET /jw?pw=... Read monthly water usage: pulse rate, current month and stored records.
GET /sf?pw=... List supported sensor types for the current build.
GET /sx?pw=... Export/import sensor configuration only.
GET /mc, /ml, /mt Configure, list and discover monitor types.

API capteurs étendue (compatible avec le firmware officiel 2.2.1(5))

Le firmware officiel OpenSprinkler 2.2.1(5) a introduit une API « Expanded Sensor ». Le firmware OpenSprinklerShop à partir de 2.4.0(228) fournit les mêmes points de terminaison sous forme de façade au-dessus de son propre système de capteurs : il n'existe qu'un seul stockage de capteurs, l'uuid officiel correspond au numéro de capteur OpenSprinklerShop nr, et l'application officielle OpenSprinkler ainsi que les clients tiers écrits pour l'API officielle fonctionnent sans modification. Les points de terminaison OpenSprinklerShop (/sl, /sc, /so, /se, ...) continuent de travailler sur les mêmes données.

Disponible sur ESP32, ESP8266 et OSPi. Les clés des points de terminaison ont trois lettres.

Point de terminaison Objectif
GET /jsn?pw=... Liste les capteurs avec la dernière mesure (sn[], count). Clés : uuid, name, type, unit, flag, status, interval (minutes), min, max, value, extra.
GET /csn?pw=...&uuid=-1&type=... Ajoute (uuid=-1 ou sid=-1) ou modifie un capteur. Paramètres communs : name, min, max, interval, unit, flag. Paramètres par type : children/action (Aggregate), pin/subtype/scale/offset/points (ADS1115), action (Weather), metric (System Internal), input (Onboard Digital), ntype (type 5, voir ci-dessous).
GET /dsn?pw=...&uuid=... Supprime un capteur ; uuid=-1 supprime tous les capteurs.
GET /jsd?pw=... Descriptions des capteurs pour les éditeurs pilotés par schéma : sensors[] (index = type), units[], enums, as, flags.
GET /jsl?pw=... Journal des capteurs : [[uuid,ts,value],...] ; fmt=csv ou fmt=binary ; filtres uuid/sid, before, after, count, cursor ; page=1 active la pagination par slot avec les en-têtes de réponse X-OS-*.
GET /dsl?pw=...&uuid=... Supprime les enregistrements d'un capteur (uuid=-1 : tout le journal). page=1 renvoie l'objet JSON de progression ; la suppression se termine en une seule requête (done=1).
GET /jpa?pw=... Facteurs d'ajustement météo (wa), capteur (sa) et total (ta) par programme, plus maxrt.
GET /jp Chaque entrée de programme porte l'objet d'ajustement capteur {flag,uuid,splits[]} en 8e élément ({} s'il n'y en a pas).
GET /cp?...&snadj=flag,uuid,x0,y0,... Définit l'ajustement capteur du programme ; snadj=0,0 le supprime. v reste obligatoire.
GET /mp?...&usa=0|1 Démarrage manuel d'un programme avec (1) ou sans (0) l'ajustement capteur. Sans usa, le comportement OpenSprinklerShop est conservé et l'ajustement est appliqué.

Correspondance des types (/jsn.type, index de /jsd.sensors) :

type Nom officiel Capteurs OpenSprinklerShop
0 Aggregate Groupes de capteurs MIN/MAX/AVG/SUM et les nouveaux MEDIAN (1004) / RANGE (1005). children sont les membres du groupe ; scale/offset des enfants doivent valoir 1/0.
1 ADS1115 Types Analog Sensor Board (10, 11, 12 par morceaux, 15-18, 30-32, 49) et types ADC OSPi (50-53). pin 1-16 = adresse de carte 0x48-0x4B x canal 0-3. Sous-types : 0 linéaire, 1 par morceaux (nouveau type 12), 10/11 SMT50, 12/13 SMT100 analogique, 15 VH400, 16 THERM200, 17 AquaPlumb. scale/offset sont appliqués après la conversion.
2 Weather Capteurs du service météo (101-110) ; action indexe enums.WeatherAction.
3 System Internal Mémoire libre (metric 0), stockage libre (1), température CPU (3).
4 Onboard Digital Nouveau type 56 : état anti-rebond de SN1 (input 0) ou SN2 (input 1).
5 Capteur OpenSprinklerShop Tous les autres types (RS485, MQTT, Zigbee, BLE, FYTA, Gardena, distant, débitmètre, ...). extra.ntype est le type OpenSprinklerShop ; les réglages propres au type se modifient avec /sc.

Remarques sur le comportement :

  • min/max bornent la valeur du capteur lorsqu'ils sont envoyés avec /csn (stockés comme cmin/cmax/clamp dans sensors.json) ; status signale les bits 3/4 lorsqu'une valeur a été bornée. Les capteurs créés avec /sc ne sont pas bornés et rapportent leur plage naturelle.
  • interval est en minutes ; le ri OpenSprinklerShop est en secondes et est arrondi à la minute dans /jsn.
  • Les sous-types intégrés rapportent leur unité native ; une autre unité du même groupe (p. ex. Fahrenheit) est refusée car le firmware ne convertit pas les unités.
  • Ajustements de programme : une courbe snadj à deux points devient un ajustement PROG_LINEAR, un palier à deux points devient PROG_DIGITAL_MIN, les autres courbes utilisent le nouveau type d'ajustement PROG_PIECEWISE (5). /jp rapporte le premier ajustement d'un programme ; les ajustements supplémentaires définis avec /sb restent appliqués par le planificateur.
