Integração do Gateway Zigbee

O OpenSprinklerPro possui capacidades nativas de coordenação Zigbee diretamente na placa do ESP32-C5. A solução de chip único ESP32-C5 suporta Wi-Fi 6 de banda dupla de 2.4 GHz, Bluetooth 5 (LE) e 802.15.4 (Zigbee 3.0 / Thread).

Utilizando a variante Zigbee do firmware, o seu controlador OpenSprinkler funciona como um coordenador Zigbee completo. Ele pode ser emparelhado com sensores de automação residencial, válvulas inteligentes, sondas de umidade do solo e monitores de temperatura para adaptar as suas programações de irrigação com base nas condições locais em tempo real.

📸 Fluxo de Configuração Guiado

Este guia passo a passo demonstra como configurar o modo de rádio, emparelhar dispositivos Zigbee e mapear os seus atributos para sensores analógicos.

Passo 1: Configuração do Modo de Rádio

Primeiro, verifique se o seu controlador ESP32-C5 está configurado para o modo de rádio correto. Por padrão, o ESP32-C5 pode operar em vários modos. Acesse as configurações de modo através do menu lateral em Setup ESP32 Mode.

Para usar o Zigbee, ative o modo Zigbee Gateway / Coordinator. Isso inicializa o rádio nativo 802.15.4 para gerenciamento de canais Zigbee, roteamento de dispositivos e formação da rede.

Passo 2: Associação e Emparelhamento de Dispositivos

Assim que o modo Zigbee estiver ativo, poderá acessar a página do ZigBee Gateway a partir do menu lateral. Esta página permite controlar o tempo de associação e gerenciar os dispositivos físicos registrados.

  1. Clique em Permit Join (geralmente por 60 segundos) para abrir a rede para novos dispositivos.
  2. Coloque o seu dispositivo Zigbee (por exemplo, válvula inteligente GIEX, sensor de solo Tuya ou sensor de temperatura Xiaomi) no modo de emparelhamento (geralmente mantendo pressionado o botão de associação por 5 segundos).
  3. O dispositivo será detectado, receberá um endereço curto e exibirá o seu endereço IEEE de 64 bits, tipo de dispositivo e qualidade de sinal (LQI).

Passo 3 (opcional): Integrações externas

Este passo é opcional e não é necessário para o funcionamento das estações ou sensores Zigbee. Abra Edit Options → Integrations apenas se quiser encaminhar os seus dados para sistemas externos: publicar as leituras dos sensores e os estados das válvulas via MQTT, registá-los no InfluxDB, ativar o acesso remoto na nuvem com OpenThings Cloud (OTC) ou enviar notificações por e-mail / IFTTT para eventos do controlador.

Passo 4: Configuração de Multi-Sensores e Calibração

Para usar os dados dos sensores para ajustes de programas, aceda a Analog Sensor Configuration a partir do menu do rodapé. Este painel exibe todos os sensores lógicos ativos, as suas vinculações físicas e o estado da bateria.

Passo 5: Adicionando/Editando um Sensor Zigbee

Clique em Add Sensor (ou edite um sensor existente) para mapear um atributo específico do dispositivo Zigbee (como porcentagem de umidade do solo ou temperatura) para um slot de sensor analógico.

Neste editor, poderá: - Atribuir um Nome facilmente reconhecível ao sensor. - Escolher o Tipo de Sensor (por exemplo, umidade, temperatura, bateria, etc.). - Selecionar o Dispositivo de Origem (Source Device) na lista suspensa dos nós Zigbee emparelhados. - Definir offsets de calibração personalizados e limites de disparo.

💧 Válvulas Inteligentes GIEX e Controlo de Zonas

Para além da leitura de sensores, o OpenSprinklerPro pode acionar válvulas Zigbee GIEX alimentadas por bateria diretamente como zonas de rega (estações). Cada saída de válvula é associada a uma estação e aberta/fechada sem fios pelo controlador — sem cablagem de 24 V, solenoides ou caixas de válvulas.

O que torna estas válvulas especiais

  • Sem fios e a bateria – a válvula funciona com baterias internas e comunica por Zigbee, pelo que uma zona pode ser colocada em qualquer local dentro do alcance do coordenador.
  • Plataforma de válvula inteligente Tuya – as válvulas GIEX expõem as suas funções como pontos de dados Tuya (DPs): comando ligar/desligar, temporizador de contagem decrescente, rega cíclica ou por duração e, nos modelos com contador, telemetria de caudal e volume.
  • Várias zonas num único dispositivo – um único GX03 oferece duas saídas totalmente independentes, pelo que um só dispositivo emparelhado resulta em duas zonas OpenSprinkler distintas.
  • Relatório de bateria – a percentagem de bateria restante é apresentada diretamente no cartão da estação no painel.

A família de produtos GIEX

Modelo Tipo Saídas / dispositivos lógicos Utilização típica
GX02 Válvula de água inteligente única 1 válvula (valve_1, DP 1) Uma zona de rega sem fios
GX03 Válvula de água inteligente de 2 zonas 2 válvulas (valve_1 = DP 1, valve_2 = DP 2) Duas zonas sem fios independentes a partir de um único dispositivo
GX04 Sensor de humidade do solo e temperatura Humidade do solo + temperatura Ajustes de programa baseados na humidade (usado como sensor analógico, ver o Passo 5 acima)

Como funcionam com o OpenSprinkler

Quando uma válvula é usada como estação Zigbee, o controlador atua como coordenador Zigbee e traduz cada execução da estação num comando ligar/desligar (ou DP Tuya) enviado para a saída de válvula correta:

  • Um dispositivo emparelhado é identificado pelo seu endereço IEEE de 64 bits.
  • Um dispositivo lógico seleciona a saída individual dentro desse dispositivo — por exemplo valve_1 (EP: 1, DP: 1) ou valve_2 (EP: 1, DP: 2) para as duas zonas de um GX03.
  • Iniciar a estação abre a válvula; o tempo de execução, os programas, os grupos sequenciais, os atrasos de chuva/sensor e o controlo manual comportam-se exatamente como uma zona cablada.

Isto é diferente da associação de sensor do Passo 5: um sensor lê dados para ajustes de programa, ao passo que uma estação Zigbee comanda ativamente uma válvula.

Configurar uma válvula GIEX como zona

  1. Emparelhe a válvula na página ZigBee Gateway (ver o Passo 2 acima). O dispositivo GIEX aparece com o seu nome amigável e endereço IEEE.
  2. No painel, abra as definições da estação (ícone de engrenagem no cartão da zona) e mude para o separador Avançado.
  3. Defina o Tipo de Estação (Station Type) como Zigbee.
  4. Escolha o dispositivo Zigbee emparelhado (por exemplo GIEX GX03 2-Zone Valve). O endereço IEEE é preenchido automaticamente.
  5. Selecione o dispositivo lógico para a saída que esta estação deve comandar — valve_1 para a primeira zona, valve_2 para a segunda.

  1. Prima Submeter (Submit). A estação passa a abrir e fechar sem fios a saída da válvula GIEX selecionada sempre que é executada.

Para um GX03 de duas zonas, repita os passos para uma segunda estação e selecione valve_2, para que ambas as saídas sejam comandadas de forma independente.

Disponibilidade da plataforma

As estações Zigbee e a função de zona GIEX requerem o controlador ESP32-C5 com a variante de firmware Zigbee. Não estão disponíveis nas builds ESP8266 ou OSPi.

🛠️ Dispositivos Suportados e Detalhes Técnicos

O firmware interno suporta clusters padrão Zigbee 3.0: - 0x0402: Medição de Temperatura (Tuya, Xiaomi, Sonoff) - 0x0405: Umidade Relativa / Umidade do Solo (GIEX, Tuya, Moes) - 0x0001: Configuração de Energia (relato de porcentagem de bateria)

Mapeamento de Dispositivos Multicanal

Ao utilizar válvulas inteligentes multicanal complexas (como a válvula de irrigação de saída dupla GIEX GX02), o coordenador divide os estados das válvulas individuais e os canais de telemetria em subdispositivos lógicos distintos. Isso garante que cada zona possa ser acionada ou ajustada de forma totalmente independente.

Coexistência de Rádio

O ESP32-C5 gerencia simultaneamente varreduras BLE, tráfego Wi-Fi 6 e pacquets Zigbee 802.15.4. Durante as varreduras de sensores BLE, o protocolo de Arbitragem de Tráfego de Pacotes (PTA) do Zigbee reduz momentaneamente a prioridade dos endpoints Zigbee para evitar colisões de rádio e perda de pacotes, restaurando a prioridade total de imediato assim que a varredura ativa é pausada.
