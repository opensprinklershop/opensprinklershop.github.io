Appendice API e piattaforme OpenSprinklerPro

Versione italiana completa dell’appendice API e piattaforme OpenSprinklerPro. Percorsi API e parametri restano invariati.

This addendum documents firmware endpoints and platform details that were added after the original 2.2.1 manual pages.

The OpenSprinklerShop firmware, including OpenSprinklerPro, uses its own firmware version numbering independent of upstream OpenSprinkler releases. Current OpenSprinklerShop firmware version: 2.4.0(228).

Correzioni piattaforma

Endpoint Piattaforme supportate Note
/uc, /uu, /us, /ub ESP32, ESP8266 Firmware online update and full backup endpoints. Not available on OSPi/Linux builds.
/sx ESP32, ESP8266, OSPi Sensor-only configuration backup/import. Distinct from /ub.
/jw ESP32, ESP8266, OSPi Monthly water-usage data.
/tg, /tl, /ta, /tc, /tx ESP32 HTTPS certificate and ACME/Let's Encrypt management.
/rk, /rp, /ru ESP32 with ENABLE_RAINMAKER ESP RainMaker status, provisioning and unlink/reset flows.
/jm, /mm ESP32 with ENABLE_MATTER Matter pairing information and commissioning window.
/bd, /bs, /bc ESP32 with OS_ENABLE_BLE BLE scan and discovered-device management.
/ir, /iw, /zj, /zs, /zg, /zd, /zo, /zc ESP32-C5 with Zigbee/IEEE 802.15.4 support Radio mode and Zigbee gateway/client endpoints.

Aggiornamento online e backup

Endpoint Scopo
GET /uc?pw=... Check update manifest and report whether a newer firmware is available.
GET /uu?pw=... Start firmware update. Advanced parameters can override URLs and hashes: zu, mu, fu, zs, ms; vt selects zigbee or matter.
GET /us?pw=... Read update status and progress.
GET /ub?pw=... Export full controller configuration for app-side backup before update.

Certificati HTTPS e ACME

Endpoint Scopo
GET /tg?pw=... Read active certificate type, subject, issuer and validity.
POST /tl?pw=... Upload custom PEM certificate and key. Reboot afterwards.
GET /ta?pw=... Read ACME configuration and status.
POST /tc?pw=... Save ACME settings and optionally request a certificate.
GET /tx?pw=... Delete ACME data and return to the internal certificate.

RainMaker e Matter

Endpoint Scopo
GET /rk?pw=... Read RainMaker status. Optional reset_mapping=1 or factory_reset=1 perform maintenance actions.
GET /rp?pw=...&uid=...&key=... Start RainMaker provisioning.
GET /ru?pw=... Unlink RainMaker account and trigger reset/reboot behavior.
GET /jm?pw=... Read Matter commissioning state, QR-code URL and manual pairing code.
GET /mm?pw=...&t=300 Open Matter commissioning window; t is optional timeout in seconds, max 900.

Consumo acqua e sensori

Endpoint Scopo
GET /jw?pw=... Read monthly water usage: pulse rate, current month and stored records.
GET /sf?pw=... List supported sensor types for the current build.
GET /sx?pw=... Export/import sensor configuration only.
GET /mc, /ml, /mt Configure, list and discover monitor types.

API sensori estesa (compatibile con il firmware ufficiale 2.2.1(5))

Il firmware ufficiale OpenSprinkler 2.2.1(5) ha introdotto una API "Expanded Sensor". Il firmware OpenSprinklerShop dalla versione 2.4.0(228) offre gli stessi endpoint come facciata sopra il proprio sistema di sensori: esiste un solo archivio sensori, lo uuid ufficiale è il numero di sensore OpenSprinklerShop nr, e l'app ufficiale OpenSprinkler così come i client di terze parti scritti per l'API ufficiale funzionano senza modifiche. Gli endpoint OpenSprinklerShop (/sl, /sc, /so, /se, ...) continuano a lavorare sugli stessi dati.

Disponibile su ESP32, ESP8266 e OSPi. Le chiavi degli endpoint hanno tre lettere.

Endpoint Scopo
GET /jsn?pw=... Elenca i sensori con l'ultima lettura (sn[], count). Chiavi: uuid, name, type, unit, flag, status, interval (minuti), min, max, value, extra.
GET /csn?pw=...&uuid=-1&type=... Aggiunge (uuid=-1 o sid=-1) o modifica un sensore. Parametri comuni: name, min, max, interval, unit, flag. Parametri per tipo: children/action (Aggregate), pin/subtype/scale/offset/points (ADS1115), action (Weather), metric (System Internal), input (Onboard Digital), ntype (tipo 5, vedi sotto).
GET /dsn?pw=...&uuid=... Elimina un sensore; uuid=-1 elimina tutti i sensori.
GET /jsd?pw=... Descrizioni dei sensori per editor guidati da schema: sensors[] (indice = type), units[], enums, as, flags.
GET /jsl?pw=... Log dei sensori: [[uuid,ts,value],...]; fmt=csv o fmt=binary; filtri uuid/sid, before, after, count, cursor; page=1 abilita la paginazione a slot con gli header di risposta X-OS-*.
GET /dsl?pw=...&uuid=... Elimina i record di log di un sensore (uuid=-1: intero log). page=1 restituisce l'oggetto JSON di avanzamento; l'eliminazione si completa in una sola richiesta (done=1).
GET /jpa?pw=... Fattori di regolazione meteo (wa), sensore (sa) e totale (ta) per programma, più maxrt.
GET /jp Ogni voce di programma porta l'oggetto di regolazione sensore {flag,uuid,splits[]} come 8° elemento ({} se assente).
GET /cp?...&snadj=flag,uuid,x0,y0,... Imposta la regolazione sensore del programma; snadj=0,0 la rimuove. v resta obbligatorio.
GET /mp?...&usa=0|1 Avvio manuale del programma con (1) o senza (0) la regolazione sensore. Senza usa viene mantenuto il comportamento OpenSprinklerShop e la regolazione viene applicata.

Mappatura dei tipi (/jsn.type, indice di /jsd.sensors):

type Nome ufficiale Sensori OpenSprinklerShop
0 Aggregate Gruppi di sensori MIN/MAX/AVG/SUM e i nuovi MEDIAN (1004) / RANGE (1005). children sono i membri del gruppo; scale/offset dei figli devono essere 1/0.
1 ADS1115 Tipi Analog Sensor Board (10, 11, 12 a tratti, 15-18, 30-32, 49) e tipi ADC OSPi (50-53). pin 1-16 = indirizzo scheda 0x48-0x4B x canale 0-3. Sottotipi: 0 lineare, 1 a tratti (nuovo tipo 12), 10/11 SMT50, 12/13 SMT100 analogico, 15 VH400, 16 THERM200, 17 AquaPlumb. scale/offset vengono applicati dopo la conversione.
2 Weather Sensori del servizio meteo (101-110); action indicizza enums.WeatherAction.
3 System Internal Memoria libera (metric 0), spazio libero (1), temperatura CPU (3).
4 Onboard Digital Nuovo tipo 56: stato con antirimbalzo di SN1 (input 0) o SN2 (input 1).
5 Sensore OpenSprinklerShop Tutti gli altri tipi (RS485, MQTT, Zigbee, BLE, FYTA, Gardena, remoto, flussometro, ...). extra.ntype è il tipo OpenSprinklerShop; le impostazioni specifiche del tipo si modificano con /sc.

Note sul comportamento:

  • min/max limitano il valore del sensore quando vengono inviati con /csn (salvati come cmin/cmax/clamp in sensors.json); status segnala i bit 3/4 quando un valore è stato limitato. I sensori creati con /sc non vengono limitati e riportano il loro intervallo naturale.
  • interval è in minuti; il ri OpenSprinklerShop è in secondi e in /jsn viene arrotondato ai minuti interi.
  • I sottotipi predefiniti riportano la loro unità nativa; un'unità diversa dello stesso gruppo (ad es. Fahrenheit) viene rifiutata perché il firmware non converte le unità.
  • Regolazioni di programma: una curva snadj a due punti diventa una regolazione PROG_LINEAR, un gradino a due punti diventa PROG_DIGITAL_MIN, le altre curve usano il nuovo tipo di regolazione PROG_PIECEWISE (5). /jp riporta la prima regolazione di un programma; le regolazioni aggiuntive definite con /sb vengono comunque applicate dallo scheduler.

Per il riferimento API legacy completo, vedere Riferimento API firmware 2.2.1.
